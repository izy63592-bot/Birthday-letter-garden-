Birthday Letter Garden
=======================

Open index.html in a browser.

Features:
- Intro page with an original, non-cliche quote
- Nature/flower themed responsive design
- Animated flower letter cards
- Long personalized letters
- Add, edit, and delete letters
- Recipient, sender, title, flower, font and text-size controls
- Automatic browser saving with localStorage
- Previous/Next navigation and keyboard arrow navigation
- Share panel and QR code
- Export Garden creates a URL containing the letters (subject to browser URL length limits)
- Mobile-friendly layout

Note:
The QR code uses the QRServer web service, so the QR image needs internet access. The garden itself can still open locally.
